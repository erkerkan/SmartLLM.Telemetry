# v1.0 release runbook

Use this checklist **before** push, NuGet, and social posts.

## 1. Build & test

```powershell
cd SmartLLM.Telemetry
dotnet restore
dotnet build SmartLLM.Telemetry.sln -c Release
dotnet test SmartLLM.Telemetry.sln -c Release
```

Expected: all tests pass (20+).

## 2. Provider smoke tests

| Provider | Env | Pass criteria |
|----------|-----|---------------|
| LM Studio | `SMARTLLM_PROVIDER=lmstudio`, model + URL set | `[activity] smartllm.chat status=ok`, tokens > 0 |
| OpenAI | `OPENAI_API_KEY` set | Real response or stub if key missing |
| Ollama | `ollama serve` + model pulled | Real response |
| Azure | `AZURE_OPENAI_*` set | Real response or stub |

```powershell
dotnet run --project samples/SmartLLM.Telemetry.Sample.Console -c Release
```

## 3. ClickHouse E2E

```powershell
cp docker/clickhouse/.env.example docker/clickhouse/.env
# edit CLICKHOUSE_PASSWORD
docker compose -f docker/clickhouse/docker-compose.yml up -d
# apply Schema/001_init.sql once

$env:SMARTLLM_CLICKHOUSE = "Host=http://127.0.0.1:8123;Database=smartllm_telemetry;Username=admin;Password=<from-.env>"
dotnet run --project samples/SmartLLM.Telemetry.Sample.Console -c Release
```

Pass: log contains `Inserted 1 row(s) into smartllm_telemetry.traces`.

SQL:

```sql
SELECT count() FROM smartllm_telemetry.traces WHERE event_time > now() - INTERVAL 1 HOUR;
```

## 4. OTLP (optional)

```powershell
$env:SMARTLLM_OTLP = "true"
$env:OTEL_EXPORTER_OTLP_ENDPOINT = "http://localhost:4317"
dotnet run --project samples/SmartLLM.Telemetry.Sample.Console -c Release
```

Verify spans in your collector UI.

## 5. Pack locally

```powershell
dotnet pack SmartLLM.Telemetry.sln -c Release -o ./artifacts
```

Inspect `./artifacts/*.nupkg` versions are `1.0.0`.

## 6. Git tag (after tests pass)

```powershell
git tag v1.0.0
git push origin main
git push origin v1.0.0
```

## 7. NuGet publish

Use `NUGET_API_KEY` in CI or:

```powershell
dotnet nuget push ./artifacts/*.nupkg --source https://api.nuget.org/v3/index.json --api-key <key> --skip-duplicate
```

Packages: Core, OpenTelemetry, Tokenizer, Security, Extensions.AI, Providers.*, Sinks.ClickHouse.
