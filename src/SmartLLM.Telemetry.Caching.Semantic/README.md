# SmartLLM.Telemetry.Caching.Semantic

**Placeholder package** — reserved for future semantic/vector cache integration. No cache logic is shipped in v1.2; do not depend on this for production caching yet.

## Install

Only if you are experimenting with upcoming APIs:

```bash
dotnet add package SmartLLM.Telemetry.Caching.Semantic
```

For observability today, use [SmartLLM.Telemetry.Core](https://www.nuget.org/packages/SmartLLM.Telemetry.Core) and [SmartLLM.Telemetry.OpenTelemetry](https://www.nuget.org/packages/SmartLLM.Telemetry.OpenTelemetry).
