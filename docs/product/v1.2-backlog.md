# v1.2 — Embeddings telemetry

**Target:** `1.2.0`

## Goals

Instrument **embedding generation** the same way as chat: OTel spans, tokens/cost estimate, ClickHouse traces.

## Deliverables

| ID | Item | Acceptance |
|----|------|------------|
| E1 | `IEmbeddingClient` in Core | `EmbedAsync` / `EmbedBatchAsync` |
| E2 | `InstrumentedEmbeddingClient` | Activity `smartllm.embeddings`, tags for model, dimensions, token estimate |
| E3 | `InstrumentedEmbeddingGenerator` | Wraps `IEmbeddingGenerator<string, Embedding>` (M.E.AI) |
| E4 | OpenAI embeddings | `AddSmartLLMOpenAIEmbeddings()` using OpenAI SDK |
| E5 | Metrics | Record embedding via `SmartLLMTelemetryMetrics.RecordEmbedding` |
| E6 | Tests | Unit tests for instrumented embedding client |
| E7 | Sample | Optional `SMARTLLM_EMBED=true` smoke in console sample |
| D1 | Docs | README + semantic conventions updated |

## Out of scope

- Vector store / RAG pipeline
- ClickHouse separate embeddings table (uses `traces` with `operation=embeddings`)
