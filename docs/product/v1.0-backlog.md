# v1.0 — Release scope

**Target version:** `1.0.0`  
**Status:** Code complete in repo — **awaiting your test pass** before public release.

## v1.0 definition

Stable SemVer API for production pilots: multi-provider chat telemetry, ClickHouse sink, PII export redaction, OTLP/console tracing, and OpenTelemetry metrics.

**Explicitly not in v1.0:** semantic cache, budget/quota enforcement, dashboard UI, failure clustering.

## Delivered in code

| Area | Item |
|------|------|
| API | `ILlmClient`, `IChatClient` instrumentation, provider DI extensions |
| Providers | OpenAI, Azure OpenAI, Ollama, LM Studio |
| Storage | ClickHouse traces/logs/costs, retry, async activity export |
| Security | Regex PII + ClickHouse export redaction |
| Observability | Traces + metrics (`smartllm.requests`, `smartllm.tokens`, `smartllm.latency.ms`, `smartllm.cost.usd`) |
| Export | `AddSmartLLMTracing` (console and/or OTLP) |
| Tests | Unit + HTTP integration test for batch writer |
| Docs | Capability matrix, migrations guide, release runbook |
