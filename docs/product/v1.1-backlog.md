# v1.1 — Tool spans & cost visibility

**Target:** `1.1.0` (shipped with `1.2.0` release line)

## Goals

1. Make **agent / function-calling** flows visible in traces.
2. Improve **cost attribution** without quota enforcement.
3. Ship **ClickHouse/Grafana query templates** for adopters.

## Deliverables

| ID | Item | Acceptance |
|----|------|------------|
| T1 | Tool call detection on `IChatClient` | `FunctionCallContent` → child span `smartllm.tool` + `smartllm.tool_call` events |
| T2 | Tool result detection | Tool-role messages → `smartllm.tool_result` events |
| T3 | Tags | `smartllm.tool_call_count`, `smartllm.tool_result_count` on parent chat span |
| C1 | Pricing expansion | Embedding model aliases + common Azure deployment prefixes |
| C2 | Optional zero-cost rows | `ClickHouseSinkOptions.ExportZeroCostRows` exports `costs` when tokens > 0 |
| C3 | Query pack | `docker/clickhouse/queries/README.md` with dashboard SQL |
| D1 | Tests | Unit tests for tool extraction helper |
| D2 | Docs | README capability matrix updated |

## Out of scope

- Hard/soft budget limits
- Semantic cache
- Built-in Grafana UI JSON export (SQL templates only)
